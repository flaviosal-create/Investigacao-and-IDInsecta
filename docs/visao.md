# LABSED Investigação

O LABSED Investigação não é um identificador biológico.

Ele é uma plataforma educacional baseada em investigação científica.

O objetivo central não é identificar organismos.

O objetivo central é desenvolver no estudante a capacidade de:

- observar;
- formular hipóteses;
- comparar evidências;
- analisar conflitos;
- justificar conclusões.

A identificação é uma consequência do processo investigativo, não seu objetivo principal.

Cada investigação ocorre dentro de um protocolo que define o seu próprio universo de hipóteses.

Por isso, a plataforma não deve empurrar o estudante para trilhas fixas do tipo:

- tecido -> órgão;
- ordem -> família -> gênero;
- etapa 1 -> etapa 2.

Essas relações podem existir como escolhas pedagógicas de conteúdo, mas não como obrigação da arquitetura do motor.

---

## Princípio Fundamental

Observação
→ Evidência
→ Hipótese
→ Comparação
→ Confirmação

A plataforma não ensina apenas respostas.

Ela ensina como construir hipóteses a partir de evidências observáveis.
