# Revisão pedagógica — protocolos de invertebrados v1

## Finalidade

Os protocolos de invertebrados apresentam um recorte de hipóteses para leitura comparativa de caracteres. Eles não têm a finalidade de identificar automaticamente um organismo, substituir uma chave taxonômica ou confirmar uma resposta a partir de um único traço.

## Critérios incorporados

- Cada protocolo é um universo investigativo autônomo.
- Toda observação pode sustentar uma hipótese e também enfraquecer hipóteses incompatíveis dentro do recorte proposto.
- A conclusão dos protocolos v1 exige evidências favoráveis distribuídas em pelo menos três estruturas observadas.
- Enquanto a leitura estiver incompleta, a sugestão privilegia uma estrutura que ajude a comparar a hipótese líder com uma concorrente.
- Um protocolo relacionado só é oferecido depois de uma conclusão e permanece opcional: ele abre outro universo de hipóteses.

## Limites didáticos

Os perfis representam combinações típicas e deliberadamente simplificadas para a atividade. Variação biológica, exceções, estágios de desenvolvimento e atualizações taxonômicas devem ser discutidos pelo docente quando forem relevantes ao objetivo da turma.

As categorias de classes utilizadas seguem recortes tradicionais de ensino e não pretendem substituir uma classificação filogenética completa.

## Comparação com Ordens de Insecta

O protocolo de ordens possui exemplos visuais para todos os seus blocos observacionais e, em várias hipóteses, aceita mais de um valor favorável para a mesma estrutura. Nos protocolos novos, cada hipótese foi inicialmente descrita por um valor típico em cada estrutura, mas a conclusão exige a convergência de três estruturas e a leitura mantém conflitos explícitos.

Como próxima etapa de conteúdo, devem ser elaborados e validados exemplos visuais e casos de variação para os protocolos de filos e classes. Eles precisam ser revisados pelo docente antes de serem convertidos em novos valores e regras, para que a ampliação represente variação biológica real e não uma sequência de confirmação.
