# Proveniência dos assets visuais

## Assets de Zoologia

As imagens em `public/assets/zoologia/` foram geradas por inteligência
artificial, conforme informado pela equipe do projeto.

Ainda precisam ser registrados:

- ferramenta e modelo utilizados;
- data ou período de geração;
- prompts, quando disponíveis;
- pessoa ou instituição responsável pela geração;
- termos de uso aplicáveis à ferramenta;
- eventuais revisões ou edições posteriores.

Até que esses dados sejam preenchidos, os assets devem ser considerados
material interno do projeto e não devem ser redistribuídos isoladamente.

As versões JPEG atualmente usadas pela aplicação foram convertidas a partir
das imagens originais para reduzir o tamanho do carregamento. A conversão não
altera a origem declarada das imagens.
