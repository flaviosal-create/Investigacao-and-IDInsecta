# Histologia V1

## Direção conceitual

Histologia deve seguir a mesma lógica investigativa usada em Zoologia.

O estudante não percorre uma chave do tipo:

- tecido básico -> tecido especializado -> órgão;
- sistema digestório -> órgão digestório;
- sistema respiratório -> órgão respiratório.

Em vez disso, cada protocolo visível abre um universo próprio de hipóteses.

---

## Protocolos visíveis

### Tipos de Tecido

O objeto de estudo é o tecido.

As hipóteses incluem os quatro tecidos clássicos e especializações relevantes:

- epitélio;
- tecido conjuntivo;
- tecido muscular;
- tecido nervoso;
- tecido cartilaginoso;
- tecido ósseo;
- tecido adiposo;
- sangue.

As observações devem sustentar hipóteses por características celulares, matriz extracelular, arranjo tecidual, fibras, lâmina basal e especializações conjuntivas.

O professor pode encerrar a investigação no tecido quando a leitura estiver suficientemente sustentada.

### Órgãos Histológicos

O objeto de estudo é o órgão.

As hipóteses devem ficar juntas no mesmo universo, sem separação por sistema.

Exemplos atuais:

- pele;
- traqueia;
- intestino delgado;
- língua;
- esôfago;
- estômago;
- testículo;
- epidídimo;
- próstata;
- vesícula seminal;
- pulmão;
- rim;
- bexiga;
- fígado;
- coração;
- tireoide;
- pâncreas;
- linfonodo;
- baço.

Tecidos, epitélios, organização geral, estruturas marcantes e conteúdo luminal entram como evidências.

Eles não funcionam como etapa obrigatória anterior.

---

## Regra para novas expansões

Ao adicionar novos conteúdos em histologia:

1. Verifique se a nova hipótese pertence ao universo atual.
2. Adicione observações morfológicas que possam sustentá-la.
3. Adicione conflitos apenas quando forem pedagogicamente úteis.
4. Crie casos representativos e casos ambíguos.
5. Evite criar protocolos por sistema anatômico.

Se uma expansão exigir uma nova pergunta investigativa, ela pode virar outro protocolo.

Se ela for apenas uma divisão taxonômica ou anatômica automática, provavelmente deve permanecer como hipótese ou evidência dentro do protocolo existente.
